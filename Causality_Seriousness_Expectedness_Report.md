4. Valid Cases
Generally, for a case to be considered a valid ICSR, it must contain 4 elements:
An identifiable patient
An identifiable reporter
Suspect medicinal product
Suspect adverse event
In these summaries, the suspect medicinal product and adverse events are provided. However, patient/reporter details are not identifiable. Therefore, we cannot guarantee that these cases all contain all 4 elements to make a valid ICSR.

6. Conclusion
From analysis of these 4 cases, it can be seen that assessing seriousness, severity, likelihood and causality of adverse reactions individually is important.
PV-201 and PV-203 are non-serious and likely.
PV-202 is serious, due to admission taking place. It is unexpected compared to expected adverse events.
PV-204 is an unexpected medically significant adverse event. It should be confirmed if this was an inpatient admission.
Where key clinical information is missing; causality is conditional.
